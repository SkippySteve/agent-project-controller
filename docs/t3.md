# T3 project interface (alpha)

The alpha includes T3 0.0.45 and Codex 0.159.0 in the Linux amd64 workspace image. T3 is the primary graphical project interface. The dashboard and CLI remain available; native Orca registration and Roamgate are outside this release.

An operator needs the controller CLI, kubectl configuration with project exec/port-forward permission, a Ready workspace using the T3 image, and a current operator-managed model grant. Deliver the grant using the procedure in [model access](model-access.md). Project agents do not receive Kubernetes or model refresh credentials.

Run `CONTROL_NAMESPACE=your-control-namespace agent-project-controller t3 WORKSPACE`. The CLI starts T3 inside that workspace and forwards it to an ephemeral IPv4 localhost port. It prints the local address and the location of a private JSON file containing a one-time pairing URL. On a Linux desktop the CLI opens the pairing page automatically using a private local HTML file. For a headless terminal, open the saved URL in your browser within ten minutes. Set `APC_T3_NO_BROWSER=true` to suppress desktop launch. Treat the file as a credential; do not paste it into chat, screenshots, tickets or shell history. Keep the command running. Ctrl+C stops the server and tunnel and removes the temporary pairing files. Only one launcher may own a workspace server at a time.

T3 listens only on the worker's loopback interface. No public ingress or worker Service is created. T3 pairing and device authentication are separate from the controller dashboard's OIDC session. The initial settings enable only Codex, through the access-only adapter. Account login, logout and refresh requests are denied. Expired or revoked grants require operator renewal; the operator procedure pauses the worker before changing a grant. T3 cannot change gVisor isolation or the project's inspecting-proxy and Cilium rules.

The repository is `/workspace/repo`. T3 state and Codex threads live under `/workspace/.apc` on the project volume. Reconnecting preserves those files; project removal deletes the owned volume. This persistence is not a disaster recovery backup. Review generated changes and use the project's scoped Git identity to propose a PR.

The initial operator CLI platform is Linux amd64. Additional platforms, providers and public/multi-device transport need separate qualification. See [release criteria](release.md) for the checks required before publishing a candidate.
